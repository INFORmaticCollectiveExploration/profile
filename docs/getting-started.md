# Getting Started

You don't need to join anything.

Start by exploring.

1. Read the Manifesto.
2. Explore Knowledge and Resources.
3. Look at existing Projects and Labs.
4. Join an activity if you find something interesting.
5. Contribute something.
6. Start something when you have an idea.

There is no required path.

You don't have to wait for a senior.
You don't have to wait for a committee.
You don't have to wait for a program.
