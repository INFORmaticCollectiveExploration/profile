# Contributing to Inforce

Anyone from Informatics can contribute.

You can contribute by:

- Writing
- Documenting
- Teaching
- Organizing a class
- Building a project
- Creating a lab
- Improving documentation
- Sharing resources
- Proposing an activity
- Maintaining existing work

## Have an idea?

Open a discussion or issue.

## Want to create something?

Start it.

## Want to improve something?

Fork / branch → make changes → pull request.

## Want to organize an activity?

Propose it, find collaborators, run it, document it.

## No permission required to have an idea.

But contributions should follow the repository rules
and respect other contributors.
